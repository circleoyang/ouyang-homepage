# 歐陽芳泉個人研究網站

個人研究、教育科技系統、研究計畫與著作出版網站。

## Online

https://circleoyang.github.io/ouyang-homepage/

## v2.0 Structure

- `index.html` — 精簡首頁：Hero、Research System Map、研究主題、研究平台與分頁入口
- `about.html` — 關於我／學術與實務經歷（條列式）
- `projects.html` — 國科會／科技部、教育部、產學合作計畫完整列表
- `publications.html` — 期刊論文、研討會論文、專書完整列表
- `app.js` — Hero 動畫與首頁互動
- `portfolio-v1-6.js` — 相容檔名；目前內容為 v2.0 首頁精簡與分頁導覽邏輯
- `styles-v2.css` — v2.0 multi-page / list-first 樣式
- `styles-v1-6.css` — publications 相容 shim，載入 v2 樣式
- `ouyang.jpeg` — 個人照片
- `assets/books/books-collage.jpg` — 專書封面拼圖（目前首頁 v2 不使用，保留資產）

## Design rule

- Homepage：研究形象與研究主張，不承載完整 CV。
- Subpages：完整資料以年份、來源、角色與文字列呈現；避免大量卡片式 UI。
